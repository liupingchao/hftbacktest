# 线程回报模板

这份模板用于：

- 业务线程回报
- 测试线程回报
- QA 验收线程回报

整段文本必须用**可直接复制的 Markdown 代码块**输出。

## 标准回报模板

```md
执行线程：
- <线程名称>

任务ID：
- <MMDDTxxx>

状态：
- 执行中 / 待验收 / 已通过 / 未通过 / 阻塞 / 作废

是否进行QA验收：
- 是 / 否

QA说明：
- 无 / 当前任务结果暂不进入QA验收，待总控确认后再决定是否派发QA验收。

files：
- <本轮改动文件，或“无代码改动”>

action：
- <本轮实际做了什么>

verify：
- <运行了什么命令，或做了什么人工验证>

done：
- <当前真正完成了什么>

blockers：
- <还有什么阻塞；没有则写“无”>

commit：
- <commit id> / 无

提交信息：
- <commit message> / 无
```

## 必填字段

- `执行线程`
- `任务ID`
- `状态`
- `是否进行QA验收`

## QA 固定话术

### 当前还不进入 QA

必须写：

```md
是否进行QA验收：
- 否

QA说明：
- 当前任务结果暂不进入QA验收，待总控确认后再决定是否派发QA验收。
```

### 当前已经进入 QA

必须写：

```md
是否进行QA验收：
- 是

QA说明：
- 无
```

## commit 写法

### 需要提交代码时

```md
commit：
- <commit id>

提交信息：
- <commit message>
```

### 不需要提交代码时

```md
commit：
- 无

提交信息：
- 无
```
