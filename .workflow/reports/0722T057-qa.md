## Findings（按严重性）

- P0：无。
- P1：existing-path fast path 绕过 legacy containment。
  `_resolve_recorded_artifact_path()` 在识别 legacy root 和检查 `..` 之前，
  先对任何已存在绝对路径执行 `recorded.resolve()` 并返回。因此，当
  legacy checkout 本身仍存在时，已存在的
  `legacy_root/../outside/secret.json` 和 legacy-root 内指向外部的 symlink
  都会被直接解析并返回 repo 外部路径。
- P1：相对 recorded path 没有 project-root containment。
  相对路径直接执行 `(PROJECT_ROOT / recorded).resolve()`；`../outside`
  和 checkout 内指向外部的 symlink 均可返回 resolved `PROJECT_ROOT`
  之外。T057 声明的“resolved candidate 必须属于 resolved
  `PROJECT_ROOT`”仍未成为统一不变量。
- P2：新增 hostile regressions 没有覆盖上述真实分支。legacy traversal
  测试创建的是当前 checkout 外部文件，但 recorded legacy 路径本身并不
  存在，因此不会进入第 130 行的 existing-path fast path；symlink 测试
  也只覆盖重定位后的 current-checkout candidate。
