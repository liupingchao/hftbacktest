
- 即 package 内实际存在第 `108` 个 filesystem entry，但 verifier 和
  full inventory 都继续声明与无 symlink 正式包相同的 `107` files 和
  identity。

代码证据：
- `examples/hyperliquid/cross_exchange_trigger_aligned_episodes.py:870-880`
  的 `_directory_inventory()` 只收集 `item.is_file()`，忽略既非
  file 也非 directory 的 dangling symlink/special entry。
- 同文件 `5383-5406` 的 artifact closure 分别用 `is_file()` 和
  `is_dir()` 构造两个 universe，没有对完整 `lstat` entry universe
  执行 exact type closure。
- 同文件 `5407-5417` 虽遍历路径名和 forbidden tokens，但没有拒绝
  symlink 或 unknown special type。
- archived runtime 对应源码与 current source byte-identical，具有相同
  行为。
- current/archive focused tests 中没有 symlink/dangling entry regression。

对照攻击：
- unknown regular file：current/archive closure 均拒绝。
- 指向现有 `/etc/hosts` 的 symlink：因 `is_file()` 跟随 target，
  current/archive closure 均拒绝。
- dangling symlink：current/archive closure 均接受；current 完整
  standalone admission 也接受。
- 独立 `lstat` inventory 正确发现：
  `{"path":"unexpected-link","type":"symlink"}`。
- 实现自己的 `_directory_inventory()` 却得到与正式包 exact 相同的
  107-file inventory 和 full SHA。

影响：
- exact artifact allowlist 和 full inventory 并未覆盖完整 filesystem
  entry universe。
- 一个未被 identity 绑定的外部路径引用可以在验收时隐藏于 package；
  target 后续出现时，package 的有效 filesystem surface 会改变，而
  已发布 core/full identity 不变。
- 这破坏 Stage 5 消费 package 时的 durable trust boundary，因此按
  P1 处理。

必须返修：
1. 在 `_verify_artifact_closure()` 和 `_directory_inventory()` 入口先
   对每个 entry 使用 `lstat`/`stat.S_ISREG`/`stat.S_ISDIR` 做 exact type
   closure；任何 symlink、FIFO、socket、device 或其他 special entry
   必须 fail closed。
2. 不得通过跟随 symlink target 把 symlink 当作普通 file/directory。
3. 新增 current/archive permanent regressions，至少覆盖 dangling
   symlink、指向现有 file 的 symlink、指向 directory 的 symlink 和一个
   unknown special entry。
4. 不改 Episode v3 research rows、feature/view/outcome semantics。
